SEND API
Mengirim magic-link autentikasi ke email melalui Firebase Identity Toolkit.

Request Body

  "email": "user@example.com"
}

Response Example

{
  "status": "success",
  "developer": "XIYU",
  "message": "Magic-link request accepted",
  "data": { "email": "user@example.com" }
}

VERIFY API
Memverifikasi magic-link lalu menjalankan aktivasi Premium sesuai alur source asli.
POST/api/verif

Request Body

{
  "email": "user@example.com",
  "magicLink": "https://provider.example/link",
  "orderId": "opsional-prefix-custom"
}

Response Example

{
  "status": "success",
  "developer": "XIYU",
  "message": "Alight Motion Pro activation request succeeded",
  "data": { "email": "user@example.com", "orderId": "AixiCodex-GPA...", "account": { "membershipStatus": "PREMIUM_ACTIVE" } }
}
